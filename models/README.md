# Models

The current app uses the two `model.pt` artifacts generated by `run_experiments.py`,
not the historical `.pth` files. Each artifact includes weights, class mapping,
preprocessing, locked support prototypes, validation threshold, data/code hashes,
label provenance and the annotation-budget unit.

After training, configure both paths in `app/config.yaml` from the same
method/budget/seed. Its default points to `runs/benchmark/protonet_k30_seed42/`.
See the root README for training and app commands.

Weights and source images are excluded from Git. There is currently no published
download for the historical checkpoints; the previous download placeholder was
not a usable link. Historical notebooks remain available for reference.
